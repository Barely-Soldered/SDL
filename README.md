# SDL (modified copy)

> **Modified copy.** This is a modified copy of SDL 3.4.8, maintained by Barely Soldered at https://github.com/Barely-Soldered/SDL (tag release-3.4.8-bs.1) for its own projects: rebuilt for meson alone, with platforms and components it does not use removed and the tree restructured. It is not the original software, which is at https://github.com/libsdl-org/SDL. The licence is unchanged; see LICENSE.txt.

Simple DirectMedia Layer is a cross-platform development library designed to provide low level access to audio, keyboard, mouse, joystick, and graphics hardware. The original project's documentation is at https://wiki.libsdl.org/.
